# Vision+

### Sistema de Gestão e Controle de Portaria para Condomínios

Landing page comercial do **Vision+**, uma solução desenvolvida para modernizar e facilitar o controle da portaria de condomínios.

O sistema foi pensado para oferecer mais organização, segurança e praticidade para porteiros, moradores e administradores.

## 🚀 Sobre o projeto

Esta página tem como objetivo apresentar o **Vision+**, demonstrar seus principais recursos e permitir que potenciais clientes conheçam a solução.

O Vision+ pode ser utilizado para auxiliar no gerenciamento das atividades da portaria, centralizando informações e tornando os processos mais organizados.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Firebase

## 🎯 Objetivo

Criar uma solução moderna para auxiliar condomínios no gerenciamento da portaria, reduzindo processos manuais e proporcionando uma experiência mais organizada e eficiente.

## 🌐 Landing Page

A página foi desenvolvida para divulgação comercial do Vision+ e apresentação da solução para possíveis clientes.
